# Student Laptop Finder

SW302 - User Interface Development, Assignment 2 (JavaScript & Tailwind CSS). A five-page web app to browse laptops, search and filter them, read full specifications, save favorites and compare them side by side.

GitHub repository: <PASTE YOUR GITHUB REPO LINK HERE>

## Install and build

Requires Node.js 18 or newer.

```bash
npm install          # installs tailwindcss, @tailwindcss/cli and @tailwindcss/forms
npm run build        # builds src/input.css into dist/output.css
npm run watch        # optional: rebuild automatically while you edit
```

## Run

`fetch()` does not work on pages opened directly as files, so serve the folder with a local server, for example VS Code **Live Server** (right-click `index.html` > Open with Live Server), or:

```bash
npx serve .
```

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home: intro, live statistics (reduce), featured laptops, theme switch |
| `laptops.html` | Catalogue: live search, category / max price / minimum RAM filters, sorting, result count, skeletons |
| `details.html?id=7` | One laptop (id read with `URLSearchParams`) with full specification table |
| `favorites.html` | Saved laptops, remove one, clear all, total and average price |
| `compare.html` | Compare 2 to 4 favorites; best value per row highlighted |

## How it works

- **Data:** `api.js` loads `data/laptops.json`; every page shows an animated skeleton first and a readable error message if loading fails.
- **Favorites and theme:** stored in `localStorage` with `JSON.stringify()` / `JSON.parse()`, shared by all pages and restored after a reload.
- **Compare:** only favorites can be compared. Adding a laptop to the comparison from its details page also saves it as a favorite. A fifth laptop is blocked with a message. The best value per row (lowest price and weight, highest RAM, storage and battery) is calculated with `reduce()` and marked with a "Best" tag.
- **Themes:** *Battery Saver Mode* (light, green) and *Performance Mode* (dark, orange) are defined with `@theme` in `src/input.css`. The switch in the header changes backgrounds, text, cards, buttons and form controls.
- **Tailwind plugin:** `@tailwindcss/forms` styles the search box, selects and slider.
- **Component classes:** `.laptop-card`, `.btn-action`, `.btn-ghost` and `.spec-chip` are defined in `@layer components` with `@apply` and reused across pages.
